
# 🧮 Calculadora Simplificada em Python

Uma calculadora em linha de comando (CLI) desenvolvida em Python, contendo as 6 principais operações matemáticas essenciais.

## 🚀 Funcionalidades

1. **Adição (+)**
2. **Subtração (-)**
3. **Multiplicação (*)**
4. **Divisão (/)** (com validação para divisão por zero)
5. **Potenciação ($x^y$)**
6. **Raiz Quadrada ($\sqrt{x}$)** (com validação para números negativos)


## 💡 Como Usar

* Siga as instruções exibidas no menu interativo no terminal.
* Digite o número correspondente à operação desejada.
* Insira os números solicitados e pressione `Enter` para ver o resultado.
